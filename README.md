# Homebrew tap

Homebrew casks for apps by Riken Patel.

```bash
brew install --cask rikenpatel02/tap/notchbar
brew install --cask rikenpatel02/tap/shotshelf
```

| Cask | App |
|---|---|
| `notchbar` | [NotchBar](https://github.com/rikenpatel02/notchbar): a Dynamic Island for Claude Code on macOS |
| `shotshelf` | [Shotshelf](https://github.com/rikenpatel02/shotshelf): sorts your screenshots into folders using on-device OCR |

Casks update automatically within a few hours of each app release.
